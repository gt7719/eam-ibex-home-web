# iBeX primary logo

`ibex-primary-logo.png` is the original “Head of iBex logo.png” supplied and designated as the primary iBeX logo by the project owner on 2026-10-22.

Preserve its black-and-white artwork. `ibex-logo-transparent.png` is the background-extracted derivative used for browser icons. The uploaded original is retained unchanged. Browser icons preserve alpha transparency. This symbol contains no wordmark; the separate iBeX wordmark rule (only X is magenta) still applies wherever that wordmark is used.
