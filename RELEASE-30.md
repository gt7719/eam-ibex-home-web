# Version 30

Version 30 is a new saved release based on Version 29. Versions 22, 27 and 29 remain unchanged.

## Included

- Floating return-to-top command inside continuous detail dialogs.
- Separate iBeX environment actions: Home resets to the first step; Close exits the environment.
- MNT-only monthly and annual pricing, with administrator-controlled monthly fee and annual discount.
- Public plan selection and payment-method readiness UI without a false payment-success state.
- Facebook post/Reel link import as a reviewable draft, explicit duplicate prevention and published-content output.
- Website-assistant TXT, Markdown and JSON knowledge import as Draft + Internal content.
- Website assistant remains isolated from iBeX System AI and tenant data.
- Shared site language/theme preferences applied to administrator surfaces without duplicate controls.

## Preserved

- Version 27 continuous inline detail articles and media placeholders.
- Version 29 layout/overlap fixes.
- Existing administrator accounts, passwords, sessions and production content.
- Protected Asset Core and connector geometry.
